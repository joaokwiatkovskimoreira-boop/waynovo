# Waynovo

Interface web responsiva para organizar fluxos de trabalho e materiais de estudo.

## Executar localmente
Abra `index.html` no navegador. Não há etapa de build nem dependências de JavaScript.

## Publicar com GitHub Pages
1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

## O que existe nesta versão
- Layout responsivo para desktop e celular.
- Tema escuro e alternância para tema claro.
- Criação e gerenciamento de uma fila local de tarefas.
- Tipos de fluxo para organização, resumo, flashcards, prática e revisão.
- Contadores de tarefas e notificações.

## Limites e segurança
Esta versão é uma interface front-end local. A fila existe apenas durante a sessão e não envia dados a servidores. Ainda não há provedor de IA conectado nem automação de submissão em plataformas externas. Integrações futuras devem usar APIs autorizadas e manter credenciais fora do código público do navegador.
